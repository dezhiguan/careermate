# CareerMate 设计系统

> 这份文档是写任何 UI 代码前必须 Read 的"宪法"。
> 严禁使用本文档以外的颜色、字号、间距、圆角。
> 所有数值都从原型 `careermate-ux-v5-flow.html` 中提取,与之严格一致。

---

## 1. 设计目标

- 移动端优先 · Web 端为辅(三栏经典结构)
- 极简对话流 · AI 是产品核心
- 不重复展示登录态(sidebar 已有头像就不在 user bar 重复)
- 列表页保留底 tab · AI 全屏沉浸时收起底 tab

## 6. 关键组件硬规范

### 6.1 移动端 frame
- 宽度: **380px** 固定(原型展示用,实际全屏)
- border: `9px solid #1e293b`
- 外圆角: 40px
- 阴影: `0 20px 50px rgba(0,0,0,.4)`
- 顶部 notch: 宽 120px × 高 24px

### 6.2 底部 5 tab
- 容器高度: **62px**
- 背景: `#fff`
- 顶部边框: `1px solid var(--line)`
- 每个 item: `flex: 1`,文字 10px / 图标 22×22

### 6.3 中间凸起 AI 按钮(★ 严格不变)
- 尺寸: **54×54**
- 定位: `position: absolute; top: -22px`
- 背景: `linear-gradient(135deg, #4f46e5, #8b5cf6)`
- 圆角: 50%
- 阴影: `0 6px 18px rgba(99,102,241,.5)`
- 外白边: `4px solid #fff`
- 中间显"职"字 18px 800

### 6.4 Web 端左 sidebar
- 宽度: **72px**(也可 64px,取 72)
- 背景: `#020617`
- icon-only 风格,每项 22×22 icon + 9px 文字标签
- 激活态: `background: rgba(99,102,241,.15)` + 左 3px primary 边框
- 全局 AI 浮按: 48×48 圆形,sidebar 中段
- 底部头像: 40×40 圆形 + 2px primary 边框 + 右下角 10×10 绿在线点

### 6.5 Web 端 user bar
- 高度: **56px**
- 背景: `#fff`
- 底部边框: `1px solid #e2e8f0`
- 内容: 页标 + 搜索(360px 宽,带 `⌘K` 提示)+ 通知 icon + 设置 icon
- **不放头像**(避免与 sidebar 重复)

### 6.6 对话气泡
- AI 气泡: 白底,`border: 1px solid var(--line)`,左上小圆角
- 用户气泡: primary 实心,白字,右下小圆角,最大宽 75%
- 头像: 32×32 圆形,渐变背景,显"职"字

### 6.7 上下文卡片(对话流里展示 JD/简历元数据)
- 白底,圆角 10px
- 头部小标签 10px ink-3 uppercase
- 标题 13px 700 ink

## 8. 导航壳铁律

### 8.1 移动端
1. **列表页(机会/面试题/市场/我的)永远显示底 5 tab**——不被任何输入框遮挡
2. **AI 小职页全屏沉浸**——底 tab 收起,输入框贴底,左上「☰」抽屉切其他模块
3. **中间凸起按钮是唯一 AI 入口**——不再有浮窗

### 8.2 Web 端
1. **每页都有左 sidebar**——4 个一级模块 + AI 浮按 + 底头像
2. **顶部 user bar 不放头像**——只放页标 / 搜索 / 通知 / 设置
3. **登录态可见性**:Sidebar 底头像(主)+ 移动端「我的」tab(主)+ AI 全屏左上汉堡抽屉(辅)

## 9. 登录态展示总表(避免重复)

| 位置 | 展示 | 点击行为 |
|---|---|---|
| Web sidebar 底部 | 头像 + 绿在线点 | 跳"我的"页 |
| Web 顶部 user bar | ⛔ 不展示 | (空) |
| 移动 AI 全屏对话 | 左上「☰」汉堡 | 抽屉切其他模块 |
| 移动底 tab「我的」 | "我的"icon + 红点 | 进我的页 |

## 10. Cursor 必须遵守的设计铁律

1. **写任何 UI 必须先 Read 本文件**
2. **写视图前必须 Read 对应原型 html**(`docs/design/prototypes/`)
3. **所有颜色必须用本文件色板**,禁止自创色
4. **所有字号、圆角、间距必须用本文件 token**
5. **移动端 frame 严格 380px**(原型),实际 App 全屏
6. **凸起按钮 `top:-22px` / `54×54` 不许改**
7. **AI 全屏对话页底 tab 必须收起**,不许保留
8. **登录态不重复展示**——按"登录态总表"
9. **图标统一用 stroke 风格**(`stroke: currentColor; fill: none; stroke-width: 2`)
10. **冲突时问架构师,不许自己设计**
