5 个板块的联动核心：Agent 工作空间

每一次围绕 JD、面试、行情或简历的 Agent 行为，都应该进入一个可恢复、可追踪、可沉淀产物的工作空间。它是产品形态和技术架构之间的连接层。

架构升级第一刀：从自研路由改成标准 Agent Kernel

当前自研路线能演示，但企业主流 Agent 更看重标准 Tool Calling、可编排 Workflow、Memory、RAG、MCP、Eval。这里建议保留业务服务，替换 Agent 内核。

P1
移动端 Agent Shell
5 tab 保持原型：机会、面试题、AI 小职、市场、我的。小职为沉浸全屏，其他 tab 的 AI 按钮只负责携带上下文进入工作空间。
Agent Runtime
新增统一 Runtime：Session、Workspace、TaskPlan、Artifact、ToolTrace、HumanConfirm。替代散落在各模块里的临时工作流。
Spring AI Alibaba Kernel
使用 ChatClient、Tool Calling、Chat Memory、RAG Advisor，并在 Spring AI Alibaba Graph/Agent Framework 上表达顺序、分支、并行、循环与人工确认。
Tool Layer
把现有 get_default_resume、create_job_match、generate_resume_from_jd、create_interview_session 等工具改造成标准工具 schema，支持多工具、多轮、参数校验、权限校验。
RAG + Memory
RAGForge 继续做外部知识库，但对 Agent 暴露为 Retriever/Knowledge Tool；用户画像、简历版本、训练弱项进入长期记忆与语义记忆。
Governance
补 Prompt 版本、Agent Eval、Guardrails、MCP、审计与成本统计，覆盖企业级 Agent 开发岗位常见要求。

主流框架选择：Spring AI Alibaba 主线，LangChain4j 做备选 PoC

你的项目是 Java + Spring Boot，目标又是中国求职市场和国内模型生态，主线建议选 Spring AI Alibaba。LangChain4j 可用于学习或单独验证 RAG/Agentic Workflow，不建议两套框架混进核心链路。

P1

Spring AI Alibaba

推荐主线Java/Spring国内模型生态

适合把现有 Spring Boot 单体升级为企业级 Agent 应用。重点用于 Agent Framework、Graph、DashScope/Qwen、MCP、工作流和可观测。

Spring AI

底座能力Tool CallingMemory/RAG

适合替换当前 LlmClient 和伪工具调用，统一 ChatClient、ToolCallingAdvisor、ChatMemory、RAG Advisor、Evaluation。

能力升级：让产品真正像 Agent，而不是 AI 页面合集

Agent 产品的差异不在“能聊天”，而在能围绕目标持续推进、调用工具、生成产物、确认动作、沉淀记忆。

P2

目标驱动

从“用户问一句”升级为“用户设目标”。 例如：准备美团 Java 后端、30 天找工作、面试前夜突击。小职自动生成任务计划和产物清单。

可执行计划

计划必须可见、可跳过、可恢复。 读取简历、分析 JD、生成版本、出题训练、市场判断，每一步有状态和失败原因。

产物中心

聊天只是过程，产物才是结果。 定制简历、匹配报告、面试复盘、谈薪脚本、补强任务都进入“我的”。

人工确认

涉及写入和覆盖的动作要确认。 覆盖默认简历、创建任务、导出最终版、生成投递话术前都要有确认卡片。

长期记忆

小职要越来越懂用户。 目标岗位、城市、期望薪资、薄弱技能、常错面试点、偏好公司类型应持续更新画像。

结果评测

Agent 结果要可测。 工具选择准确率、参数正确率、RAG 命中率、简历质量、面试评分一致性都要有测试集。

执行路线：按重要性从高到低推进

不要先重做所有页面。先把 Agent 工作空间和工具协议打通，再补框架、工作流、记忆、评测。

PLAN

P0：统一产品联动与工作空间

保留 5 tab；新增统一 AgentWorkspace 和 Artifact 概念；所有“让小职处理”都携带上下文进入小职，产物沉淀到“我的”。

P1：标准 Tool Calling 替换自研工具路由

把现有 AgentTool 改造成 Spring AI 工具 schema；支持多工具调用、参数校验、权限检查、工具结果回传模型。

P1：引入 Spring AI Alibaba Graph

把“按 JD 生成简历”“创建面试训练”“市场谈薪”改成可视化、可恢复、可重试的工作流 Agent。

P2：Memory 与 RAG 产品化

短期记忆用 ChatMemory，长期记忆沉淀职业画像、弱项、偏好；RAGForge 封装为统一 Retriever Tool，补引用和质量评测。

P2：多 Agent 从“专家工具壳”升级为协作体

ResumeAgent、OpportunityAgent、InterviewAgent、MarketAgent、ProfileAgent、CriticAgent 分工明确，Supervisor 统一调度。

P3：MCP、Eval、Guardrails、招聘市场能力补齐

将 RAGForge、简历、JD、任务暴露为 MCP 工具/资源；建立 Agent 评测集；补 Prompt 版本、注入防护、敏感信息保护和成本看板。
