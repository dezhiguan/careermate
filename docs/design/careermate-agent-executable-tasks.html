Executable Roadmap for Cursor

CareerMate Agent 升级任务清单

这是一份按重要性从高到低排列的可执行任务页。目标是把当前 5 tab 求职产品升级为真正的 Agent 工作台，并把后端从自研 Agent 路由逐步升级到 Spring AI Alibaba / Spring AI 主流技术栈。

4阶段：P0 产品闭环、P1 Agent 内核、P2 智能能力、P3 企业治理
16可执行任务：每个任务有范围、验收和依赖
5板块联动：机会、面试题、小职、市场、我的
1原则：先打通 Agent 工作空间，再做框架替换
总览 P0 必做 P1 技术主线 P2 能力增强 P3 企业化 执行顺序 Cursor 规则

总览：5 个板块如何变成一个 Agent 产品

每个 tab 都有清晰职责，所有 AI 行为统一进入小职工作空间，所有结果统一沉淀到“我的”。

MAP
机会找目标：JD、公司、岗位、薪资、匹配差距。所有“分析 JD / 定制简历 / 准备面试”都进入小职。
面试题练能力：根据 JD、简历、缺口出题、评分、讲解、追问，并回流弱项。
AI 小职中枢：理解目标、生成计划、调用工具、请求确认、产出简历/题目/任务/话术。
市场做判断：薪资区间、技能趋势、公司情报、谈薪依据，进入小职生成策略。
我的存资产：简历版本、训练记录、求职档案、任务清单、工作空间历史。

P0：必须先做的产品闭环任务

这些任务先于框架替换。没有统一工作空间和产物沉淀，后面接 Spring AI Alibaba 也只是换技术，不会让产品更像 Agent。
