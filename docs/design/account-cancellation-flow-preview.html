关键点（V2·委托网关）：
· 注销/撤销委托 auth-gateway（deletion-request POST/DELETE），网关为唯一权威；冷静期对齐网关 30 天。
· 确认注销后立即登出 + 吊销全部会话；期间账号冻结，不进主界面、不产生新数据。
· 再次登录：登录能过（CANCELLING 已放行），但落"注销中"中间页而非主界面。
· "恢复账号"= 委托网关撤销 → status 置回 ACTIVE → 进主界面正常使用。
· 到期由网关 cron 匿名化身份 + 发 user.deleted 事件；CareerMate 订阅该事件清本地数据（匿名化 user + 删简历/对话/投递等）。CareerMate 侧无 cron、无 Redis 锁（网关行级锁已保证多副本安全）。
已定稿决策（V2）：
1. 冷静期 30 天（对齐网关，零跨服务改动）；各页面按到期时间动态显示剩余天数与日期。
2. 注销/撤销委托 auth-gateway 的 deletion-request 接口，复用平台既有注销中枢。
3. "确认离开" = 仅登出返回登录页，保留冷静期兜底。
4. 清理 = 匿名化 user 主记录 PII + 删除个人内容，status=DELETED；由 user.deleted 事件驱动，非自建定时任务。
5. 恢复账号 = 委托网关撤销、直接回原状态，不重走 onboarding。
6. CareerMate 侧不需要 Redis 锁 / cron —— 网关已用行级锁做到多副本安全。
